* 🐳 Orchestration de l'ensemble avec **Docker Compose**
* 🔄 Pipeline CI avec tests, builds Docker et publication d'images

**Technologies :**
`React` `Node.js` `PostgreSQL` `Docker` `Docker Compose` `Prometheus` `Grafana`
